BRAHIM ENNAJJAR — PREMIUM PERSONAL WEBSITE
===========================================

CONTENTS
- index.html   Page structure, SEO metadata, project links, schema
- styles.css   Responsive black-and-gold design and animations
- script.js    English/Arabic toggle, mobile navigation, scroll effects
- favicon.svg Browser tab icon

OPEN THE WEBSITE IN VS CODE
1. Extract this ZIP into a folder.
2. Open VS Code.
3. Choose File > Open Folder and select this extracted folder.
4. Open index.html.
5. If Live Server is installed: right-click index.html > Open with Live Server.
   If that command is missing, open Extensions (Ctrl+Shift+X), search
   "Live Server" by Ritwick Dey, and install/enable it.
6. You can also double-click index.html in File Explorer to preview it,
   although Live Server is better while editing.

IMPORTANT BEFORE PUBLISHING
1. Replace https://YOUR-DOMAIN.example/ in index.html:
   - canonical link
   - og:url
   - og:image (set a real public image URL)
   - Person schema "url"
2. Replace YOUR-EMAIL@example.com in the contact button with your real public email.
3. Check that all public project details are accurate.
4. Upload the files to your hosting provider. Use a real domain and HTTPS.
5. Add the site to Google Search Console and submit a sitemap when you publish.
   This helps discovery but does not guarantee ranking or appearance in search.
6. Add a robots.txt and sitemap.xml once the final domain is known.

LANGUAGE
- The button in the top navigation switches between English and Arabic.
- The chosen language is saved in the browser.
- Arabic mode switches the page to RTL layout.
- The theme can be toggled on desktop by pressing the T key.

SEO NOTES
- The page includes a title, meta description, robots directive, Open Graph tags,
  canonical placeholder, and basic Schema.org Person structured data.
- Replace placeholders before publication. Do not leave example URLs in production.
- Google/ChatGPT search visibility is not guaranteed just by creating a website.
  A public, crawlable site with accurate content and useful links is a good start.

No personal photograph is used in this design. The hero artwork is built in CSS.
